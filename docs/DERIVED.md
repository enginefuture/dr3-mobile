# Published interface metadata

The repository contains version IDs, Build IDs, SHA-256 fingerprints, module/segment sizes, ABI symbol names, offsets and bounded instruction-match constants needed to reject unknown builds and apply targeted adaptations. These are not complete game modules, resources or shader programs.

`config/` locks Diablo III 2.7.7.92380. `tools/mobile_graphics_profile.py` contains short instruction patterns for guarded resolution/projection changes and independent synthetic checks. The upstream patch contains compatibility-layer code and protocol layouts; shader bodies, generated game maps, executable images and captured payloads remain private.

Tests construct synthetic CPK sectors, NVN commands, shader interface text and network messages. Tests that refer to the private corpus must explicitly skip when it is absent. Published counts and redacted diagnostic summaries do not distribute the underlying corpus. See [GAME_FILES.md](GAME_FILES.md).
